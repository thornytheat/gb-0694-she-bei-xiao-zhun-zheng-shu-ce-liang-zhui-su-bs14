# 数据定义

证书有效期与量程双约束；参考标准也须在校准时有效，证书撤销向下游传播并检测环。

输入字段：cert, device, alias, parent, valid_from, valid_to, minimum, maximum, unit, revoked, measured_at, value, measure_unit, version。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

校准电压量程闭区间[min,max]，证书日期为半开[valid_from,valid_to)。父证书需在子证书生效日有效；撤销按追溯性撤销处理，所有下游测量拒用。同编号证书定义冲突会使其及下游失去证明力。样例是电压仪器，未处理非线性量程和不确定度传播。

## 结算批定义

结算批的身份只由供应商与结算期决定（`sha256("settlement|供应商|结算期")`），因此同一结算期重跑、换证据文件或重复提交都落到同一批，不产生第二笔应付。

**按证书结算**：明细一行一张证书，金额 = 每条可结算测量 × 结算单价（默认100）。同一证书换过设备别名或代记，只在 `aliases` 中体现，绝不拆成两行，避免重复结算。

**状态划分**：

| 状态 | 条件 | 本期处理 |
|---|---|---|
| 应付 | 该证书本期全部测量可采用 | 计入本期应付，封账入账 |
| 暂扣 | 仅有效期或溯源暂未成立（`INVALID_WINDOW`、`REFERENCE_CONFLICT`、`MISSING_REFERENCE`、`REFERENCE_EXPIRED`、`CYCLE`） | 不发，挂在本批，等证据 |
| 拒付 | 已撤销、超量程或号证冲突导致不可用（`REVOKED`、`OUT_OF_RANGE`） | 不发，不计应付 |

**结算期**：半开 `[YYYY-MM-01, 次月01)`，只取测量日在期内的记录；期外测量进入 `snapshot.excluded` 供复核，不计本期应付，避免跨期重复付款。

**晚到证据**：撤销（`revocation`）与改证（`amendment`）。证据会改写证书簿，并按证书簿重算**全部**测量的有效区间、量程和溯源（改证可改有效期、父证书、设备、别名与量程下限）。因此一次上游改证可能让已出测量失效并重算，而不是只影响被点名的证书。

- 封账前：证据直接参与本批重算，`revision` 自增、`decision` 重置为待复核，`evidence[].disposition = 本批`。
- 封账后：冻结快照与付款凭证不改写，只登记证据并按冻结快照计算边际金额，写入后续结算期的扣回/补付（`carries`，`disposition = 转 YYYY-MM 期扣回/补付`）。同一撤销源的多个下游只在源头计一次，下游记 0 元，避免重复扣回。
- 新测量批次若显示已付证书失效或暂扣证书可付，重跑同一结算批时会自动登记为晚到证据并转入后续期。

**幂等与回溯**：证据身份为 `证书 + 类型 + 收到日 + 变更内容`，重复提交只返回既有记录。付款台账（`ledger`）按 `结算批 + 凭证类型` 去重，重复封账不追加。已封账快照 `snapshot`、`evidence`、`carries`、`ledger` 均可通过页面、API 与 `evidence.csv` 完整回溯。
