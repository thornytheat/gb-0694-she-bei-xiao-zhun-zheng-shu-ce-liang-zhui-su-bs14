# 设备校准证书与测量追溯

检验机构质量员使用本工具完成：合并仪器使用与校准证书，裁决测量是否在有效可追溯链内；随后按证书生成可复核的供应商结算批，处理晚到撤销与改证。

## 业务

证书有效期与量程双约束；参考标准也须在校准时有效，证书撤销向下游传播并检测环。七个追溯模块加一个结算模块：证书接收、设备别名、有效区间、量程匹配、溯源链路、测量裁决、撤销复核、供应商结算。模块独立API及页面入口见docs/API.md。样例中包含真实常见脏数据，原因码和原始行号在隔离面板及证据文件中可复核。

供应商按证书结算，但撤销与改证常比账单晚到。结算页按“供应商 + 结算期”生成唯一结算批，写清本期应付、暂扣、拒付与上期调整；封账前晚到证据直接重算本批，封账后只留痕并转入后续期扣回/补付，已付款历史仍可回溯；同一证书换过设备别名或代记只计一行，重跑同一结算批不重复记账。

## 启动与验证

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

打开 http://localhost:18208 。点击“运行样例”，或展开输入区提交CSV。切换七个模块查看计算依据。复核区可通过或退回，同一版本仅允许一次复核。证据CSV包含所有阶段与隔离行，批次内容不因复核变更。左侧底部“供应商结算”进入结算页，可按样例生成结算批、登记晚到撤销/改证、复核并封账。

SQLite保存在命名卷records；容器重建保留历史。只在确认不再需要数据时执行 `docker compose down -v` 重建。端口可通过.env中的PORT调整。本地也可 `pip install -r requirements.txt` 后 `python -m app.main`。

## 定义与限制

详见docs/DATA-DICTIONARY.md、docs/DEPTH.md。单文件最大5MB/一万行，本工具按确定性文件离线复算，不查询外部业务系统。源码位于app，测试位于tests，样例位于sample_data。
